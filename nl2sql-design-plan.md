# SQL Natural - Design Plan

## Subject & Audience
**Subject**: Natural Language to SQL Query Platform  
**Audience**: Hackathon judges, data analysts, non-technical users  
**Single job**: Turn English questions into actionable SQL with visual feedback

## Visual Identity
Drawing from the database/schema world: structured, precise, with a hint of playfulness.

## Color Palette
- **Primary**: `#2563EB` (Sapphire Blue) - trust, precision, data
- **Secondary**: `#10B981` (Emerald Green) - success, execution, results  
- **Accent**: `#F59E0B` (Amber) - caution, processing, transformation
- **Neutral Ground**: `#F8FAFC` (Off-white with blue bias)
- **Neutral Text**: `#1E293B` (Dark slate)
- **Surface**: `#FFFFFF` (Pure white for cards)

Dark mode:
- **Ground**: `#0F172A` (Deep navy)
- **Text**: `#E2E8F0` (Light slate)
- **Surface**: `#1E293B` (Slate)

## Typography
- **Display**: `"JetBrains Mono", monospace` - technical, precise (for SQL/code)
- **Body**: `"Inter", sans-serif` - readable, approachable (for UI text)
- **Scale**: Modular scale with ratio 1.25

## Layout Concept
Two-panel layout with clear flow direction:
- Left: Natural language input and schema explorer
- Right: Generated SQL and visual results
- Center: Animated transformation visualization showing the "English → SQL → Results" journey

## Key Visual Elements
1. **Schema Explorer** - Tree visualization of database tables
2. **Query Flow** - Animated flowchart showing transformation
3. **Results Canvas** - Gravity-inspired 3D visualization for data
4. **Confidence Meter** - Visual indicator of query accuracy

## Interactive Moments
1. **Query Generation** - Pulse animation as NL transforms to SQL
2. **Schema Highlight** - Tables/columns light up as user types
3. **Results Loading** - Progressive fill of visualization
4. **Query History** - Timeline of past queries with quick replay

## Content Strategy
- Avoid technical jargon in UI labels
- Show "before/after" state clearly
- Provide immediate feedback for each step
- Celebrate successful queries with subtle animation

## Theme Implementation
Design will work in light/dark/system preferences with careful color token management. The blue/green/amber palette maintains legibility across themes.
